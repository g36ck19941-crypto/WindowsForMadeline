# CDR-013 — Bounded Atlas Page Decoder

Date: 2026-09-21

## Added function

- `AtlasDataDecoder` converts one readable stream into an immutable BGRA32 frame.
- The decoder reads little-endian width and height, a strict `0` or `1` alpha flag, and byte-length pixel runs.
- An alpha-enabled run stores its alpha byte; a zero-alpha run stores no color bytes. Every visible run stores blue, green and red bytes in that order.
- The decoder preserves stored channel bytes. It does not recolor, un-premultiply or otherwise transform the source.
- Input bytes, dimensions and decoded bytes have independent budgets.
- Zero-length, overflowing, truncated and trailing runs fail with stable `ATLAS_DATA_*` codes.
- The output owns a defensive pixel copy and exposes a lowercase SHA-256 content fingerprint without logging pixels.

## Format evidence and confidence

The public Monocle engine mirror confirms that Packer metadata resolves each page name to a `.data` stream. Its mirrored version delegates the image stream to the graphics framework and does not expose the Celeste-branch run decoder. The byte layout above is therefore a bounded synthetic contract independently implemented from secondary format observations. It is not yet a real-install compatibility claim.

CDR-016 remains responsible for opt-in, read-only conformance against a user-selected正版 installation. A mismatch there must change the decoder contract; it must not be hidden by fallback logic.

## Role in the project

This turns a compressed atlas page recipe into exact in-memory pixels. CDR-012 tells us where a sprite is; CDR-013 supplies the page pixels from which a later task can cut it out. It still does not parse animation definitions, extract a sprite, render a character or prove compatibility with a real installation.

## Safety boundaries

- Public decoder input is `Stream` only; it cannot choose or enumerate files.
- Tests use generated bytes only.
- No game installation, commercial image, GUI or desktop surface is accessed.
- Decoded frames are never persisted by this task.
