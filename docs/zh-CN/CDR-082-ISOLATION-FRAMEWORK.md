# CDR-082：隔离模块的旧框架编译兼容

2026-10-03，Primary。仍待验收、未上传。

## 它在项目中的作用

我们新写的外围工具原本只按新框架编译。现在它也能编译成原版恢复库采用的4.7.2旧框架库，避免后续连接时先卡在工具的编译接口上。

## 更新了什么，是否符合预期

只调整了我们自己的兼容写法，没有修改原版源码。使用已授权的4个系统引用，哈希前后核对，再直接调用已有编译器；没有下载、安装或读取游戏目录。

旧框架编译零错误。静态检查确认实际目标是4.7.2，只有基础库引用，没有原生导入或嵌入资源；重复编译摘要一致。生成库未运行。

符合“我们自己的适配模块也能按旧框架编译”的预期。**不是原版角色接入或运行成功**；原版发行目标4.5与此次4.7.2的运行兼容仍未证明，不是安全沙箱。
