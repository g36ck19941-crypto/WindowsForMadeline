# CDR-016 真实安装只读一致性验证

## 结果

CDR-016 已在开发者指定的正版 Windows 安装上通过。验证器只以只读方式打开 3 个必需资源文件，重复构建两次目标目录、重复解码两次必要 Atlas 页，并比较读取前后的文件状态。

安全证据只包含哈希和数量，不包含安装绝对路径、像素、XML、Atlas 原始数据、可执行内容或其他商业素材字节。

## 实际验证到的内容

- 3 个源文件、1 个 Atlas 页、6824 个 Atlas 条目。
- 5 个明确选中的定义：Madeline、Theo Crystal、水母、Bumper 和 Puffer。
- 93 个动画、706 个已解析帧。
- 重复解码与重复建目录的指纹一致。
- 读取前后文件长度、修改时间和 SHA-256 完全一致。
- 游戏启动、GUI 启动、安装目录写入、持久化商业素材字节均为 0。

真实文件暴露并固化了几类兼容差异：`.meta` 页名可能省略 `.data`，动画路径可能带一个尾随分隔符，Atlas 路径大小写可能不同，数字帧后缀可能不是固定两位；共享 Atlas 路径元数据和空头发元数据也已覆盖。

## 具体验收方式

1. 双击根目录的 `验证当前版本.cmd`。预期依次出现 `15/15`、`27/27`、`35/35`、`31/31`、`44/44`、`29/29`、`10/10`，最后显示离线验证通过。它不会读取真实安装。
2. 如需亲自复核正版安装，把安装文件夹拖到 `验证真实安装兼容性.cmd` 上，或双击后粘贴路径。
3. 预期最后出现 `CDR-016 REAL CONFORMANCE PASSED`，并显示 `installation_writes=0`、`commercial_bytes_persisted=0`。
4. 摘要报告只写到项目的 `artifacts/cdr-016-verification`，不得出现在游戏安装目录。

## 它在项目中的作用

简单说，这一步证明“我们写的资源读取器不只会吃自己编的测试数据，也确实能读懂你这份正版安装，并稳定找出五类目标角色/物品的帧”。它给以后真正显示角色提供了可信的素材目录输入。

但这一步还没有显示角色，也不能证明动画正确、操作手感接近原版。它也没有验证其他游戏版本、全部实体、关卡、Mod、音频、模拟、渲染或桌面交互。

## 验收后开始的功能

CDR-020：只用程序生成的几何实现固定 60 Hz 的 Actor/Solid 模拟核心，包括整像素移动、亚像素余量、碰撞顺序、移动平台携带和 LiftSpeed。CDR-016 未经验收前不会上传。
