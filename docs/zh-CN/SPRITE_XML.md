# CDR-014 — 有界精灵动画定义读取器（中文验收）

> 英文规范：`docs/SPRITE_XML.md`。若两者不同，以英文版为准并修正中文镜像。

## 它在项目中的作用

前两阶段已经能读出合成图页“目录”和像素。本阶段补上“动画说明书”：精灵叫什么、使用哪组图、播放哪些帧、速度与循环方式、从哪个动画开始，以及原点、位置、头发和携带物的逐帧偏移。后续 CDR-015 才能把这些说明与真正的 Atlas 条目对上。本阶段还不能裁图、显示角色，也不能证明正版安装兼容。

## 新增功能

- 读取调用方提供的 XML 字节流；必须显式列出允许的精灵 ID，不会自己寻找游戏目录。
- 对选中的精灵读取 `Anim`/`Loop`、帧序列、延迟、起始动画、原点/对齐、位置，以及 `Metadata/Frames` 中的头发和携带偏移。
- 支持帧编号、范围、重复写法；对缺失的帧列表明确记为“使用全部帧”，不凭空猜测具体帧。
- 限制输入与展开数量，禁用 DTD/外部实体；对重复、缺失、非法路径、未知节点、元数据帧数不符等返回 `SPRITE_XML_*` 错误。
- `goto` 文本只保存、不执行；真实动画跳转和素材对应关系仍由后续任务验证。

## 具体验收方式

1. 双击仓库根目录 `演示当前进度.cmd`。浏览器应打开 `artifacts/cdr-014-demo/index.html`；看到程序生成的 8×6 图页、2 个目录区域、2 个精灵/2 个动画定义，且明确写有 `diagnostic_placeholder=true` 和“商业素材字节 0”。这是累计项目进度展示，不是原版 Madeline 显示演示。
2. 双击 `验证当前版本.cmd`。预期出现 `VERIFICATION PASSED`，构建 0 警告/错误；五组结果分别为 `15/15`、`27/27`、`35/35`、`31/31` 和 `40/40`。
3. 可核对 `src/CelesteDesktop.AssetWorker.SpriteXml/` 只接收字节流，演示与测试只使用程序生成输入。代理没有打开 GUI、游戏或真实安装目录。

## 验收后开始的功能

验收后仅开始 CDR-015 的合成素材目录：把精灵动画引用与合成 Atlas 条目建立确定、无歧义的关联。验收不授权读取真实正版安装、启动 Celeste/Everest 或 GUI、观察桌面，也不授权保存商业素材。
