# 本地行为参考

CDR-070 是只供开发使用的本地反编译参考建立器。它不启动游戏，就能帮助我们查看角色和实体的状态顺序、数值、碰撞框及交互逻辑。以前只能猜测或运行游戏观察的一部分行为，现在可以从你自己的正版安装建立方便查阅的本地证据。

## 安全边界

- 只接受你手动指定的绝对安装路径，不扫描磁盘、注册表或进程。
- 优先只读 `Celeste.dll`，没有时才读 `Celeste.exe`；不写安装目录。
- 结果只放在 Git 忽略的 `local-cache`；Git 只保存工具、测试和说明。
- 不保存或上传反编译源码、IL、商业素材、真实安装路径。
- 不加载或执行游戏程序集，不启动游戏或游戏 GUI。
- 首次使用会说明并询问是否从官方 NuGet 源下载固定版本、MIT 许可的 ILSpy，不会静默全局安装。

## 验收方法

1. 双击 `建立本地行为参考.cmd`，输入或拖入正版安装文件夹。
2. 首次使用按提示输入 `Y`；看到 `LOCAL_REFERENCE_COMPLETED`。
3. 确认游戏没有启动、安装目录没有被写入。
4. 运行 `git status --short`，不应出现 `local-cache` 中的反编译文件。
5. 工程门禁应显示 10/10 专项安全测试通过。

## 在项目中的作用

它为以后校准 Player、Theo、Puffer、Seeker 等行为提供更可靠的本地依据，减少凭感觉猜数值和状态顺序。它不会自动修好实体，也不会把商业代码变成我们的代码；每项行为仍需重新写成自己的合同、实现和测试。它也不能单独证明手感完全一致，运行时细节和人眼体验仍需另外验收。
