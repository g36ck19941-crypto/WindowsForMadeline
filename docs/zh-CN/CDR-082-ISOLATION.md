# CDR-082：本地隔离适配

2026-10-03，Primary。按本次授权实现，待验收、未上传。

## 它在项目中的作用

这次做的是角色外围的“测试控制台”：预先规定每一步经过多少时间、输入什么按键，并明确拒绝外部服务。未来原版角色接入后，可用同一份输入重复检查，而不需要读取你的键盘或启动整个游戏。

它不计算角色位置、速度或碰撞，没有重新写玩法；也没有修改原版行为源码。

## 更新了什么，是否符合预期

- 每步固定1/60秒；预设方向和按键能区分刚按下、持续按住、刚松开。输入复制保存，外部修改原列表不会改变回放。
- 输入非法、序列耗尽、会话关闭会明确报错，不悄悄补零继续。
- Steam、声音、窗口、绘图设备、真实输入、素材读取、文件写入和原版执行，8类请求全部明确拒绝。
- 45项合成检查通过，包括重复回放、4096步时间检查、非法数据、生命周期和拒绝服务。进度摘要另有4项正反例检查。

符合“独立适配工具可用”的预期，**未达到“原版角色已经接入适配并运行”**。它不是系统安全沙箱，无法阻止其它代码绕过接口调用系统。

## 仍未证明什么

原版的时间、输入、场景和素材服务还没连接。原版使用的是静态服务，不会因为我们创建接口就自动改用它。此工具用net8编译，原版旧框架的桥接兼容也未证明。

没有运行恢复代码，没有读取新素材，没有游戏、GUI或真实输入，也没有角色生成或移动。无需再次试编译商业源码即可验证本次适配。

## 具体验收方式

1. 双击根目录“验证本地隔离适配.cmd”。会看到5步预设输入和8种拒绝记录，最后应为 `ISOLATION_VERIFIED passed=45 failed=0 originalBound=false recoveredCodeExecuted=false`。这是输入/时间记录，不是角色运动。
2. 双击“验证当前版本.cmd”。应有上述45项及此前回归317、探针26、编译合成13、编译摘要4、隔离摘要4，最后 `OFFLINE_VERIFIED`。窗口测试始终排除。
3. “演示当前进度.cmd”的说明页面新增“运行之前，隔离准备做到哪一步？”；它明确说明尚未接入角色。严格不打开GUI时设置 `CDR_DEMO_NO_OPEN=1` 和 `CDR_NO_PAUSE=1` 后生成页面。
4. 出错请提供最后错误信息及 `ISOLATION_VERIFICATION_FAILED`，不要发送商业源码或DLL。
