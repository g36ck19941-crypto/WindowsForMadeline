# CDR-075 — 下蹲与安全起身

规范以英文 `docs/PLAYER_DUCKING.md` 为准。

角色站在地上时，明确的下蹲输入会缩小身体碰撞范围。标准程序生成角色从高 11 像素变成高 6 像素，宽度保持 8，脚底位置不变。默认下蹲高度为 `min(6, max(1, 站立高度-1))`，也允许调用方指定合法高度；高度为 1 的角色不会假装进一步下蹲。

蹲着时不会继续加速跑，只会以当前项目的摩擦值 500 px/s² 减速，所以能利用原有速度滑进矮处。单纯向下瞄准、快速下落、主动穿过单向平台分别使用不同输入。空中不能新发起下蹲；已经蹲下的角色在空中继续按住时可维持小碰撞范围。

松开下蹲或请求普通跳跃时，先检查完整站立空间。头顶有普通障碍物就继续蹲着，记录阻挡物 ID，也不会跳进天花板。头顶有空间时安全恢复站立，跳跃才按已有规则处理。检查发生在每个 Normal 时间点开始处；如果该步移动刚好滑出天花板，下个时间点才起身。跳跃缓存继续遵循已有的有界规则。

Core 的尺寸变更必须在模拟步骤内、针对已登记角色执行；失败不会改变位置或高度，成功也不改变宽度和亚像素余量。单向平台不阻挡向上的身体扩展，已被挤压禁用的角色不能变更尺寸。

日志区分 `DuckStarted`（开始下蹲）、`UnduckBlocked`（本次起身被阻挡）与 `UnduckCompleted`（成功起身）。快照公开是否下蹲、实际碰撞范围和阻挡物。进入下蹲会取消撞墙速度保留，蹲着撞墙不会重新保留速度。

专项为 Core 48/48、Player 72/72。九步程序演示的高度为 6/11、脚底恒为 y=11；第 7、8 步不能起身，第 9 步障碍移开后恢复；事件计数 1/2/1，全程无重叠，重复运行一致。

这仍为部分校准：没有爬行、冲刺/攀爬下蹲联动、原版碰撞箱偏移或完整手感结论，没有真人操作、商业动画声音或真实桌面显示；本任务没有访问游戏安装或本地反编译参考。
