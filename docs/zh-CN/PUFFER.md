# CDR-046 Puffer（河豚）任务说明

## 它在项目中的作用

这一项让纯离线模拟里出现一个会在左右边界之间游动的 Puffer。角色靠近后，它会先进入短暂预警，再爆炸并把角色沿远离自身的方向弹开；冷却结束后回到出生点。Puffer 只发出“应该变成什么速度”的效果，Player 再通过自己的入口实际应用，因此爆炸判断与角色运动可以分开定位问题。

它为以后连接 Puffer 原版动画、声音和正式 App 交互提供了可重复的状态基础，也验证了两个 Puffer 互不污染。

## 当前边界

- 只使用程序生成的游动边界、目标位置和固定 tick 输入。
- 不打开可见窗口，不读取实时输入，不访问游戏或安装目录，不保存商业素材。
- 游动速度、触发范围、预警时间、弹射速度和重生时间是独立设计基线，不代表已经完美还原原版。
- 原版特殊交互、动画、声音、正式 App 路由和人眼可见效果仍未证明。

## 具体验收方式

1. 双击项目根目录的 `演示当前进度.cmd`。
2. 打开生成的 `artifacts\cdr-046-demo\index.html`，找到 CDR-046 Puffer 表格。
3. 应看到 20 个固定时间点、8 次游动、3 次转向、3 次预警、3 次爆炸、3 次弹射请求、2 次重生、1 次中心回退、1 次范围外忽略和 3 次 Player 实际应用；重复运行完全一致。
4. 表格中应能看出游动边界、斜向/中心回退/左向弹射，同时另一个 Puffer 始终独立保持 `Swimming`。
5. 再双击 `验证当前版本.cmd`。
6. 应看到构建 0 警告、0 错误，Puffer `59/59`，累计 `684/684`，最后出现 `CDR-046 OFFLINE VERIFICATION PASSED`。

通过这些步骤只证明 Puffer 的纯离线程序生成行为符合本任务合同，不代表已经显示原版 Puffer、连接正式 App、读取实时输入或完美还原商业版数值与特殊交互。
