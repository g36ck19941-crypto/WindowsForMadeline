# CDR-021 Madeline 普通移动与跳跃

## 实现内容

`CelesteDesktop.Player` 在固定 60 Hz 的模拟步骤中，只接收调用方给出的不可变输入快照。它不会读取键盘、手柄、时钟、窗口或操作系统输入。

当前实现包含地面跑动与减速、空中操控、超速回落、重力与按住跳跃时的半重力、普通/快速下落上限、土狼时间、跳跃缓冲、水平跳跃加速、可变跳跃高度、碰撞后速度归零以及明确的状态事件。每个 tick 都能生成不可变快照。

数值与更新顺序依据 Celeste 官方公开 `Player.cs` 中能确认的事实重新设计实现，没有逐行复制。公开资料不能确认发行版本的所有输入缓冲配置和周边系统，因此本任务如实标为 `partial`，不是“完整原版手感”。

参考证据：<https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs>。仓库只记录公开源码能够确认的事实，不复制其实现文本。

## 具体验收方式

1. 双击 `演示当前进度.cmd`。
2. 查看 CDR-021 的 24 行玩家表：速度应逐步达到 90；第 7 tick 应出现 `Jumped`；跳跃最高位置应到 `Y=-16`；重复运行应标为“完全一致”。
3. 双击 `验证当前版本.cmd`。前八组是已有回归，最后一组应为 `30/30`，总计 249 项，随后 CDR-021 演示清单核验通过。
4. 全过程不读取真实安装，不启动游戏、GUI 或真实桌面，也不读取实时输入。

## 它在项目中的作用

简单说，这一步让前一任务搭好的“物理地板”上终于有了能跑和跳的角色逻辑。后续冲刺、蹬墙、攀爬，以及 Theo、水母、弹簧等交互，都可以共用同一套位置、速度、计时器和事件，而不是各写一套互相打架的逻辑。

它还没有实现冲刺、贴墙下滑、蹬墙跳、攀爬、体力、搬运、转角修正、单向平台、水中/寒冷/太空变体、实时控制、角色显示或桌面交互，也不能证明完整发行版手感已经一致。

## 验收后开始的功能

CDR-021 已于 2026-09-29 验收，允许上传独立分支。CDR-022 随后用纯合成输入与几何实现冲刺、贴墙/蹬墙、攀爬、体力和边缘转换。
