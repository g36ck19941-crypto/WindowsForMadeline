# Atlas 元数据读取器（中文镜像）

> 英文规范：`docs/ATLAS_METADATA.md`。如有差异，以英文版为准。

## 本次新增功能

CDR-012 新增独立的 `.meta` 读取器。它只接收一个受大小限制的字节流，并生成不可修改的 Atlas、页面和条目描述。它自己不会打开路径，也不包含文件系统访问、Worker 请求、图片解码或显示功能。

它能读取的结构包括版本、打包器名称、页面列表，以及每个素材条目的页面位置、矩形、裁剪偏移和原始画布大小。

格式事实分别核对了公开的 [Crunch 二进制格式说明](https://github.com/ChevyRay/crunch#binary-format) 和 [desk-madeline 的独立格式观察](https://github.com/solstice23/desk-madeline/blob/master/CelesteAtlas.cs)。本项目没有复制它们的实现。是否与用户的真实安装完全一致，要等 CDR-016 才能验证。

## 它在项目中的作用

CDR-012 让项目能够读懂 Atlas 的“目录”：某个精灵名称在哪一页、占用哪块矩形，以及被裁掉透明边缘后应该放回原始画布的哪个位置。这是下一步解码页面像素前必须先有的索引。

它目前仍不能解码 `.data` 像素、找到 Madeline 动画、显示角色，也不能证明已经兼容用户的真实游戏安装。

## 安全限制

- 默认最多消费 16 MiB 输入；
- 单个字符串最多 1,024 个 UTF-8 字节；
- 最多 64 页、总计 100,000 个条目；
- 坐标、尺寸和画布范围最大 16,384；
- 严格检查 UTF-8 和字符串长度编码；
- 统一斜杠和 Unicode 写法；
- 拒绝绝对路径、盘符、空路径段和 `..` 穿越；
- 拒绝 Windows 通配符、尾随点/空格和保留设备名歧义；
- 页面路径和条目 ID 不允许出现大小写或规范化后的重复；
- 拒绝负坐标、空尺寸、范围溢出和不可能的裁剪；
- 拒绝截断和任何尾随字节；
- 失败时不返回半成品描述。

稳定错误码统一属于 `ATLAS_META_*`。

## 具体验收方式

在仓库根目录运行：

```powershell
.\tools\Verify-CDR012.ps1
```

预期结果：

- Release 构建：0 警告、0 错误；
- CDR-010 回归：`RESULT total=15 passed=15 failed=0`；
- CDR-011 回归：`RESULT total=27 passed=27 failed=0`；
- CDR-012：`RESULT total=35 passed=35 failed=0`。

CDR-012 的测试只使用程序生成的字节，不读取 `.meta` 文件、商业素材或游戏安装，也不启动游戏或 GUI。

## 当前局限

这只是合成格式验证，不是 `asset_exact`。读取器尚未接入 Worker IPC，没有读取真实 `Gameplay.meta`，也不能解码 `.data` 页面。

## 验收后开始的功能

验收 CDR-012 后只开始 CDR-013：使用程序生成的像素游程实现有界 `.data` RLE 解码器，并精确核对合成 BGRA32 像素。真实安装访问仍要等 CDR-016 单独授权。
