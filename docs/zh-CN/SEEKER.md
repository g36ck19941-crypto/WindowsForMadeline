# CDR-047 Seeker（追踪者）任务说明

## 它在项目中的作用

这一项加入了项目里第一个多阶段敌对实体状态机。程序生成的 Seeker 会巡逻、发现一个合格目标、预警、追逐、蓄力、冲刺，随后根据结果记录“命中目标”或“撞墙”，进入眩晕并恢复。这样以后接入正式 App、动画和更复杂交互时，可以逐阶段定位问题，而不会让 Seeker 直接依赖 Player、渲染、桌面或文件。

本任务仍不能证明原版寻路、复杂地形避障、完整伤害/反弹规则、时间和数值、动画声音或可见桌面表现。还原度保持 `partial`。

## 隔离与日志

- Seeker 自己管理程序生成的巡逻边界、目标锁定、丢失目标宽限、蓄力/冲刺方向、撞墙、眩晕和恢复。
- 命中只输出带目标身份的不可变事实，不冒充 Player 已死亡或已经应用效果。
- 第二只 Seeker 独立运行，不会被第一只的状态污染。
- 稳定事件分别记录巡逻、发现、追逐、蓄力、冲刺、命中、撞墙、眩晕、恢复、目标丢失、停用/启用和忽略目标。

## 具体验收方式

1. 双击根目录 `演示当前进度.cmd`。
2. 打开 `artifacts\cdr-047-demo\index.html`，找到 CDR-047 Seeker 表格。
3. 确认能看到一次命中目标、一次撞墙、两次眩晕/恢复、一次丢失目标返回巡逻，以及第二只 Seeker 始终独立巡逻。
4. 双击 `验证当前版本.cmd`。
5. 应看到 Release 0 警告、0 错误，Seeker `66/66`，累计 `750/750`，最后显示 `CDR-047 OFFLINE VERIFICATION PASSED`。

这些步骤只证明程序生成的纯离线状态行为，不证明原版素材、商业版精确手感、Player 死亡、正式 App、实时输入或人眼可见桌面输出。
