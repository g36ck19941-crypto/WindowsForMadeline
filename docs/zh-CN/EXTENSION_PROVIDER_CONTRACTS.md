# 纯数据扩展提供器合同

CDR-060 把以前只写在文档里的未来扩展口变成了可编译、可测试的接口。它没有实现地图解析器，也没有实现 Mod 读取器。

## 素材提供器

`IAssetSourceProvider` 只允许三件事：说明来源、按“逻辑资源编号+固定类型”查找，以及在字节上限内返回复制后的纯数据。描述中必须带提供器编号、来源类型、优先级、版本、长度和 SHA-256；查找结果明确区分“找到、没找到、因规则拒绝”。

接口里没有文件路径、文件流、系统句柄、回调、程序集或可执行资源类型。以后即使接入真实来源，也仍然必须经过单独加固的 AssetWorker。

## 世界内容提供器

`IWorldContentProvider` 只能在调用者给定的数量上限内返回不可变房间。房间目前只能描述：

- 整数范围；
- 矩形 Solid；
- 出生点；
- 项目已经支持的实体摆放；
- 来源、世界、房间编号和 SHA-256 摘要。

其中没有脚本、玩法回调、渲染对象、文件对象或原始地图格式。Simulation 不需要知道数据来自原版地图还是未来的纯数据扩展。

## 它在项目中的作用

简单说，这是给未来地图和纯数据 Mod 留出的“安全插座”：以后新增读取器时，只能把整理好的有限数据插进来，不能把整个 Mod 程序、文件系统或脚本塞进模拟核心。这样未来功能可以扩展，但现有角色手感和安全边界不会被格式代码直接污染。

当前只用了程序生成提供器，没有读取 Celeste 地图、Mod 目录或游戏安装，也没有加载 DLL、Lua 或脚本。CDR-061 和 CDR-062 仍是独立任务，不能因为本任务通过就自动开始。
