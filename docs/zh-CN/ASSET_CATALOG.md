# CDR-015 规范化素材目录

## 完成结果

CDR-015 把调用方提供的 Atlas 目录、精灵定义和图页字节流组合成按实体隔离的不可变素材目录。本里程碑只使用程序生成输入，不定位、读取游戏安装。

## 它在项目中的作用

之前三个解析器只能分别读懂目录、像素和动画定义；本任务第一次把它们接成“某个角色或物品有哪些可用动画帧”。以后渲染模块可以分别取得 `player/idle` 和 `spring/idle`，不会因为动画都叫 `idle` 而互相覆盖。

它仍不能证明真实 Celeste 安装与这些规则兼容，也没有显示角色或实现操作手感。真实安装核验属于 CDR-016，必须另行取得新授权；移动和显示还要等后续模拟、渲染任务。

## 主要安全规则

- 必须显式给出实体允许列表；图页只通过字节流接口提供。
- 只解码白名单帧真正引用的页面，同一页面在一次构建中最多解码一次。
- 玩家、弹簧等各自保留独立目录，不建立全局同名动画或位图表。
- 裁剪区域会放回透明的原始帧尺寸，并校验边界。
- 实体、动画、帧、页面和像素均有上限，失败使用稳定的 `CATALOG_*` 错误码。
- 目录指纹由规范化源摘要、目录结构和帧哈希确定；模块没有磁盘缓存或文件系统读取实现。

## 具体验收方式

1. 双击根目录 `演示当前进度.cmd`。
2. 在报告中确认：`CDR-015`、`diagnostic_placeholder=true`、2 个实体目录、2 个目录帧、只解码 1 页、商业素材字节为 0。
3. 双击根目录 `验证当前版本.cmd`。
4. 确认 Release 构建为 0 警告/0 错误，并且 CDR-010 至 CDR-015 所有测试均为 0 失败。

本次验收不等于授权读取真实安装、启动游戏/GUI或进行真实桌面观察。

## 验收后开始的功能

验收后可上传 CDR-015 纯生成数据版本。下一项 CDR-016 是只读真实安装一致性验证，但必须由你再次明确授权并限定安装目录和证据边界后才能开始。
