# CDR-001 中文验收说明

> 英文规范：`docs/reviews/CDR-001-ACCEPTANCE.md`。本文件只方便开发者阅读。

## 本次更新新增了什么

CDR-001 新增项目架构、诊断、安全解析、参考来源、还原状态和任务顺序合同。本阶段没有新增可运行功能，没有实现解析器或桌面角色，没有启动 Celeste/Everest、GUI，也没有读取真实游戏安装或加入商业素材。

## 验收代表同意以下边界

1. 产品不得启动、注入、控制或修改 Celeste/Everest。
2. 商业资源只留在用户电脑上；后续解析由独立、受限、只读的 AssetWorker 完成。
3. 素材正确、行为正确、画面提交和人眼可见必须分别验证。
4. 关卡/地图还原和纯数据 Mod 素材通过文档化接口延后，而不是永久拒绝；剧情/过场和可执行 Mod 行为仍不属于当前产品。
5. 验收后只允许开始 CDR-010 的纯合成文件系统验证。
6. 真实游戏安装读取仍要等到 CDR-016 并重新获得明确授权。

## 五分钟验收方法

1. 查看中文架构说明，确认模块方向和独立 AssetWorker 符合预期。
2. 查看中文诊断合同，确认解码、生成、Present 和人眼可见不是同一件事。
3. 查看中文素材安全合同，确认不自动扫描 Steam、不启动游戏、不写游戏目录、不分发商业字节。
4. 查看中文还原矩阵，确认所有运行能力仍诚实标为 `unstarted`。
5. 查看中文任务顺序，确认下一步只有 CDR-010 合成安装验证。

## 验收后的权限边界

验收只允许开始 CDR-010，不授权读取真实安装、启动 GUI、进行真实桌面观察、开始 CDR-011，或上传任何商业素材。

如果接受以上边界，请回复：

> 验收 CDR-001，开始 CDR-010
