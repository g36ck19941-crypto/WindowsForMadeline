# CDR-070 验收说明

状态：已完成本地实现，等待开发者验收；尚未上传。

## 这次完成了什么

- 增加显式选择正版安装的本地行为参考建立器。
- 固定使用仓库本地 ILSpy 11.1.0.9782，首次下载前必须明确同意。
- 反编译结果按程序集哈希存放在 Git 忽略的 `local-cache`，失败时只清理本次临时目录。
- 清单只保存文件名、大小、哈希、工具版本和文件数，不能保存路径、源码或商业字节。
- 增加中文双击入口、中英文规则和隔离安全测试。

## 它在项目中的作用（通俗解释）

这相当于给开发工作增加一本“只放在你电脑上的原版行为参考书”。以后校准 Madeline、Theo、Puffer、Seeker 等功能时，可以先核对原版的状态顺序、碰撞框和数值，再把观察结果重新写成我们自己的规则和测试，减少靠猜造成的偏差。

它不是把原版代码直接塞进项目，也不会自动改善现在的实体。它只让后续实现有更可靠的依据。

## 你怎样验收

1. 双击 `建立本地行为参考.cmd`，选择同一个正版安装；应复用已有缓存并显示 `LOCAL_REFERENCE_COMPLETED`。
2. 确认 Celeste/Everest 和游戏 GUI 都没有启动。
3. 双击 `验证当前版本.cmd`；应看到构建 0 警告/错误、专项 10/10、总计 866/866。
4. `git status --short` 中不应出现任何 `local-cache` 文件。

## 仍不能证明什么

它不能单独证明角色手感已经还原，也不能证明桌面显示、实时输入或运行时特殊情况。后续每个行为校准仍需单独实现、测试和验收。CDR-060 仍是另一个待验收版本，本任务没有替它完成验收。
