# CDR-082：原版输入测试的依赖预检

2026-10-03，Primary。已收到原版输入/时间测试授权，但按“遇到依赖疑点先停止”的要求，在执行前停下。

## 它在项目中的作用

避免测试器在我们不知情时，从缓存以外加载运行组件。能编译的恢复库不代表它自己就能运行，外围依赖也必须确认。

## 具体发现

项目缓存里有恢复后的原版库，但本次DLL清单没有找到它需要的3个XNA运行库。之前找到的XNA在系统GAC里，当时核准的是编译器读取元数据，不是原版测试运行加载。

原版输入使用XNA数据类型，引擎类型还继承XNA的Game。若直接启动测试，系统可能自动从GAC解析依赖；这会越过本次“仅使用缓存”的边界，相关初始化或原生副作用也尚未审查。

没有启动原版测试，没有加载恢复库或调用其初始化、输入更新时间方法，没有复制系统文件、读取安装、新素材或启动GUI。不是原版测试通过，也不是运行失败。

## 需要确认的范围

是否允许把**此前已找到的3个系统XNA库**只读复制到本地忽略缓存，先审查依赖和初始化路径？仍不读取游戏安装、不下载、不安装、不调用图形设备、真实输入、Steam或音频。

实际运行只使用审查通过的输入数据类型及必要托管依赖；遇到未审查的原生调用、窗口或设备路径继续停止。复制成功不能当成运行安全证明，不擅自用FNA代替。

如果你已有包含这些库的指定缓存，也可以提供它的路径。原版输入测试的授权已记录，不需要重新授权同一件事；需要确认的是依赖来源和用途。

## 具体验收方式及下一步

本次只有预检记录，没有新运行入口。确认上述依赖范围后，先审查，再决定能否执行已授权的限定原版测试。角色创建、素材与显示不在其中。
