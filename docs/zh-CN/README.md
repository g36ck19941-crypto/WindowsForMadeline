# 中文验收资料

本目录只为开发者阅读和人工验收提供中文镜像。

- 英文文件是实现、测试和代理执行时的唯一规范来源。
- 中文文件不得覆盖或改变英文合同；若两者存在差异，以英文版为准，并应修正翻译。
- 每次需要开发者验收的更新，应同步提供对应中文说明。
- 自动化验证与项目进度演示必须分开说明；人工验收优先使用根目录可双击 `.cmd` 或正式 `.exe`，不再要求开发者手动启动 PowerShell 脚本。
- `PROJECT_MEMORY.md`、`STATUS.md` 和 `docs/handoffs/CURRENT.md` 已包含中文项目状态或简明交接信息，不在这里重复维护完整副本。
