# Player Normal/Jump 行为校准

## 这次具体做什么

CDR-071 只补一个明确缺口：Madeline 从移动平台起跳时，会继承平台带给她的一部分速度。

通俗地说：站在向右移动的平台上起跳，角色应该保留一些向右惯性；平台向上顶时，起跳会更高；平台向下走时，不应该把角色的跳跃向下拖。继承量有上限，避免高速平台把角色弹到异常速度。

项目自己的规则是：水平继承限制在每秒 `-250` 到 `250`；向上最多额外继承每秒 `130`；向下速度不加入跳跃。实际应用值会进入不可变快照和结构化事件，方便定位轨迹差异。

## 它在项目中的作用

这会让“站在移动桌面表面或移动实体上起跳”的手感更接近原版，也让平台速度是否真正传给角色可以直接从日志和测试中看到。

它只校准这一条规则，不代表 Player 已完全还原。下蹲、持物减速、低摩擦环境、特殊跳跃、动画声音和人眼手感仍需后续小任务分别处理。
