# CDR-042 确定性 Spring 更新

- 新增独立固定 tick Spring，包含不可变接触、生命周期、目标效果、快照和事件合同。
- 支持四个方向、激活、压缩、冷却、复位、停用/启用和“离开后才能再次触发”。
- 新增按轴替换的通用外部速度效果；Player、Theo、Glider 都会实际应用，Spring 模块不直接依赖它们。
- 新增 42 项程序生成测试，覆盖安全默认输入、三个目标、双 Spring 隔离和确定性重放。
- 累计报告新增 30 tick Spring 轨迹，包含 3 次激活、3 次发射、3 次复位及三个目标各一次实际应用。
- 行为仍为 `partial`；正式 App 组装、原版接触/数值和可见素材集成尚未证明。
