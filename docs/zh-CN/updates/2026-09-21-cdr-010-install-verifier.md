# CDR-010 — 显式合成安装验证器

日期：2026-09-21

## 新增功能

- 新增 .NET 8 Contracts 和 Install 项目。
- 新增只验证调用方传入根目录的验证器，并执行规范化包含检查。
- 拒绝根目录、父目录和文件本身的重解析点。
- 新增稳定、受限的 `INSTALL_*` 问题合同，失败时不暴露绝对路径。
- 新增只查看元数据的系统文件适配器和可注入合成文件系统。
- 新增隔离的离线验证命令。

## 验证证据

- 命令：`.\tools\Verify-CDR010.ps1`
- Release 构建：0 警告、0 错误。
- 合成测试：15 通过、0 失败。
- 真实安装读取：0。
- 目录枚举或文件内容读取：接口能力为 0。
- 游戏、Everest 或 GUI 启动：0。
- 商业素材文件：0。

## 当前局限

这些证据只证明验证器能针对合成元数据状态进行确定性结构验证。它不能证明任何真实安装已经受支持，也不能证明 Atlas 可以解析或原版素材能够显示。

## 具体验收方式

运行 `.\tools\Verify-CDR010.ps1`，确认最后一行为 `RESULT total=15 passed=15 failed=0`。

## 验收后开始的功能

CDR-011 将实现有界 IPC 合同与 AssetWorker 生命周期监管，并使用合成方式测试崩溃、超时、取消和非法信封。它不会解析素材或读取真实安装。
