# CDR-021 更新：合成 Normal/Jump 行为

CDR-021 新增独立于平台的玩家控制器，包含跑动、减速、空中操控、重力、快速下落、土狼时间、跳跃缓冲和可变跳跃。它只接收程序生成的输入快照，并输出不可变的逐 tick 快照和明确事件。

累计离线演示新增 24 tick 的跑跳轨迹和完全一致的重复重放。30 项专项测试使完整离线回归达到 249 项，Release 构建无警告、无错误。

这是新的离线玩家行为，但还原状态仍是 `partial`：目前覆盖公开资料能够确认的数值与顺序；完整发行版行为、实时输入、渲染和桌面集成都不在本任务内。CDR-021 等待开发者验收，未上传。
