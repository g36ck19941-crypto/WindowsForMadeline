# CDR-013 — 有界 Atlas 图页解码器

日期：2026-09-21

## 新增功能

- 新增不可修改的 BGRA32 像素帧所有权和 SHA-256 指纹。
- 新增只接收字节流的有界 `.data` 游程解码器。
- 新增 alpha 标志、游程长度、精确填满和尾随数据验证。
- 新增 29 项生成数据、不可变性和 API 表面测试。

## 它在项目中的作用

它提供之后裁切单张角色或物品精灵所需的整页内存像素。它还不解析动画、不裁切精灵、不显示内容，也不能证明已兼容真实安装。
