# CDR-012 — 有界 Atlas 元数据读取器

日期：2026-09-21

## 新增功能

- 新增不可修改的 Atlas、页面和条目描述合同。
- 新增只接收字节流、不访问文件系统的 `.meta` 读取器。
- 新增输入、字符串、页数、条目数和尺寸预算。
- 新增严格 UTF-8、规范长度和逻辑路径验证。
- 新增重复、矩形、裁剪、截断和尾随数据拒绝。
- 新增稳定 `ATLAS_META_*` 错误以及 35 项生成字节/API 表面测试。

## 它在项目中的作用

它提供后续像素解码和素材目录所需的 Atlas“目录”。它目前不解码像素、不解析动画，也不显示任何内容。
