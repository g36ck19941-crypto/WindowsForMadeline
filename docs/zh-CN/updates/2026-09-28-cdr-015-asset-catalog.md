# CDR-015 更新 — 规范化合成素材目录

## 新增功能

程序生成的 Atlas 目录、图页字节和精灵定义现在可以组合成按实体隔离的不可变目录。系统只按需打开必要图页，一次构建中每页最多解码一次，并把裁剪区域补回透明的完整帧。

目录保存调用方提供的源摘要，并对规范结构与帧内容哈希生成确定性 SHA-256。不同实体中同名动画不会互相覆盖。本次没有加入文件系统读取、全局位图表或磁盘缓存。
