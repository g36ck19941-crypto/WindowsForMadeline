# 双击入口通俗说明更新

日期：2026-09-29  
类型：启动器和文档体验更新；没有新增运行功能

## 更新了什么

- `演示当前进度.cmd` 现在会先解释累计演示生成什么、报告里应该看到什么，以及为什么程序生成像素不能证明真实桌面可见。
- `验证当前版本.cmd` 现在会解释 365 项检查能证明什么、怎样判断成功，以及哪些结论仍不在证据范围内。
- 两个入口都会提示：失败时优先保留第一个错误和它所在的阶段。
- `AGENTS.md` 已加入持久规则，后续面向开发者的根目录启动入口也必须采用这种通俗说明结构。
- `.cmd` 已明确使用 Windows CRLF 换行；验证器源码中的证据标记保持 ASCII 安全，避免 Windows PowerShell 5.1 错读 UTF-8 中文字面量。

## 它在项目中的作用

开发者不需要先理解内部模块名，就能分清“演示说明项目现在会做什么”和“验证说明代码有没有通过检查”，也不会把离线通过误认为角色已经出现在桌面。

## 仍不能证明什么

本次没有修改动画、模拟、渲染或桌面行为。CDR-032 仍然等待开发者验收，也没有因为这次说明更新而上传。
