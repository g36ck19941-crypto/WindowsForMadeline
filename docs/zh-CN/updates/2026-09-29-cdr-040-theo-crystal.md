# CDR-040 Theo Crystal 更新说明

这次增加了一个独立的 Theo 水晶模拟模块。它可以被拿起、携带、放下和投掷，也会在程序生成的墙和地面上反弹、落地，并继承移动平台速度。受压失败只影响对应 Theo，不会拖坏 Player 或另一个 Theo。

项目作用：这是第一个完整走通“独立实体 + 稳定日志 + 交互矩阵 + 累计演示”的对象，为后续水母、弹簧等实体建立可复用结构。

验收证据：Release 构建 0 警告/错误，Theo 专项 37/37，总回归 402/402；36 tick 演示包含拿起、投掷、撞墙反弹和落地，并可完全重放。没有访问安装目录、打开 GUI 或保存商业素材。

限制：当前数值是独立设计的离线基线，行为仍为 `partial`；没有原版 Theo 像素、动画连接或真实桌面显示。
