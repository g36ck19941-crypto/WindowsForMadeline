# CDR-041 Glider 更新说明

这次增加了独立的 Glider（水母）模拟模块。它能被拿起、携带、放下和投掷，会输出携带者缓降请求，Player 能通过通用外部效果入口实际应用；它也会展开缓慢下落、撞墙反弹、落地并继承平台速度。摧毁或受压只影响对应 Glider。

项目作用：它在 Theo 的“可携带实体”基础上增加了对 Player 生效但不直接改写 Player 的窄效果合同，为以后正式组装水母缓降和更多实体效果提供边界。

验收证据：Release 0 警告/错误，Player 33/33、Glider 42/42，总回归 447/447；48 tick 演示包含拿起、缓降请求、Player 实际应用、投掷、反弹和落地，重放一致。没有访问安装目录、打开 GUI 或保存商业素材。

限制：当前数值是独立设计的离线基线，行为仍为 `partial`；正式 App 尚未负责持续传递缓降效果，也没有原版动画和真实桌面显示。
