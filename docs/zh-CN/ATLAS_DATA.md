# CDR-013 — 有界 Atlas 图页解码器

日期：2026-09-21

## 新增功能

- `AtlasDataDecoder` 把一个可读字节流解码成不可修改的 BGRA32 像素帧。
- 它读取小端宽度、高度、严格为 `0` 或 `1` 的 alpha 标志，以及按字节长度记录的像素游程。
- 带 alpha 的游程包含 alpha；alpha 为零时不再包含颜色。可见游程按蓝、绿、红顺序存储颜色。
- 解码器原样保留通道字节，不调色，也不进行预乘或反预乘变换。
- 输入字节数、尺寸和解码后字节数分别受限。
- 零长度、越界、截断和尾随数据使用稳定的 `ATLAS_DATA_*` 错误拒绝。
- 输出帧自己持有像素副本，并提供小写 SHA-256 指纹；日志不包含原始像素。

## 格式依据与可信度

公开 Monocle 引擎镜像确认 Packer 元数据会把每个页面名解析到 `.data` 字节流，但该旧镜像把图像交给图形框架，没有公开 Celeste 分支的游程解码细节。因此，本任务根据次级格式观察，独立设计并实现了一个有界的合成格式合同；现在还不能宣称已兼容真实安装。

CDR-016 仍需另行授权，才会对用户明确选择的正版安装做只读一致性验证。如果格式不符，应修改合同和解码器，不能用静默 fallback 掩盖。

## 它在项目中的作用

简单说，它把“压缩的整张素材页说明”还原成内存里的像素。CDR-012 告诉后续代码某张小图在哪里，CDR-013 提供那张大图页的像素，之后才能裁出角色或物品帧。它还没有解析动画、裁出精灵、显示角色，也没有证明真实游戏文件一定兼容。

## 安全边界

- 公开解码接口只接收 `Stream`，不能自行选择或枚举文件。
- 测试只使用程序生成的字节。
- 不读取游戏安装，不接触商业图片，不启动 GUI，也不观察桌面。
- 本任务不把解码帧写入磁盘。
