# CDR-031 匿名桌面几何

CDR-031 新增隔离的桌面适配器，只输出匿名可见表面的几何、DPI 和计算速度。平台无关层负责过滤、临时匿名编号、单调时间和汇总诊断；Windows 层只读枚举顶层表面。

## 隐私边界

Windows 层只调用可见性、遮蔽状态、矩形和 DPI API。它不调用标题/文字 API，不抓取像素，不读取进程、可执行文件或窗口类身份，不读取输入，也不把原生句柄暴露出去。句柄到随机令牌的映射只短暂存在于进程内存，公开快照只有 `surface-000001` 形式的编号。

`DESKTOP_SNAPSHOT_CAPTURED` 只记录序号、可见/过滤数量和最小/最大 DPI；日志和证据不包含原始窗口列表或源令牌。

## 验证证据

- Release 构建：0 警告、0 错误。
- 桌面合成测试：19/19；总回归：337/337。
- 已授权的隐藏只读 Windows 验证：1/1，只输出数量与 DPI 范围汇总。
- 累计演示：2 个程序生成快照，最终 2 个可见表面，其中 1 个移动；报告不保存真实桌面数值。
- 标题、内容、截图、输入、可见 GUI、游戏/安装访问和商业素材字节：0。

## 具体验收方式

1. 双击 `演示当前进度.cmd`，查看 CDR-031 匿名几何表。应有 2 个程序生成快照、匿名 ID、DPI 和速度。
2. 确认报告明确写明桌面数据是程序生成的，且没有标题、内容、截图、输入或原生句柄。
3. 双击 `验证当前版本.cmd`。最后应出现 `CDR-031 READ-ONLY VERIFICATION PASSED`；Desktop 专项应为 `19/19`，真实只读验证应为 `1/1`，并只输出一行汇总。

验证入口会在你本机按已授权边界读取当前桌面，但不会打开可见 GUI。

## 它在项目中的作用

简单说，这一步让未来的桌面角色只知道“哪里有一个可见表面、它多大、移动多快”，却不知道它属于哪个软件，也看不到里面的内容。后面才能在保护隐私的前提下做桌面碰撞和站立支持。

它还没有把 Madeline 放到真实窗口上，没有连接商业动画帧，没有打开 Overlay，也没有证明人眼可见。

## 验收后开始的功能

开发者已于 2026-09-29 验收 CDR-031，可在出站审计后上传独立分支。CDR-032 已另行授权，只允许把已验证素材目录连接到离线动画呈现，不能把渲染节奏反向耦合进物理；可见 GUI 仍然禁止。
