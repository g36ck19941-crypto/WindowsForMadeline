## Distribution and practical limits
Tracked repository contains our tools, adapters, contracts, synthetic tests and summary records only. Recovered commercial source/IL, original game assemblies/assets and derived commercial builds stay ignored and local. No automatic upload, bundled game content or blanket MIT claim; licensing of separate tooling does not license commercial code. Local-only storage is not a guarantee that every use is legally permitted.
The desired architecture is original behavior in a local isolated core, connected through our thin adapters to asset reading and a desktop host. We cannot promise successful full reconstruction until source identity, dependency closure and compilation probes pass. Unsupported dependencies must produce explicit phase/type/error diagnostics.
Current code does not yet implement that original core. CDR-080 is a deletion and tooling preparation milestone, not runnable functionality.
